01 · 市面 40+ 款主流 AI Harness 深度解剖与基因提取

看清每一家的看家本领与硬伤，一次把天花板拉满

综合 2026 年 50 款 Harness 架构评分榜（Kendr Research）、11 款主流系统 400 万行源码解剖（arXiv:2609.00006）及 Terminal-Bench 实测数据：目前没有任何单一产品在全部十个维度拿满分。Gorness 的核心策略是用 Go 静态单二进制把各派系经过生产验证的最强机制一次性熔铸进同一套架构契约。

400 万行源码审计确立的三大设计铁律

所有在真实复杂工程中胜出的顶级 Harness，无一例外遵守以下三条反直觉共识：

0 / 11
铁律一：严禁引入重型通用 Agent 框架（LangChain / LangGraph / AutoGen 全缺席） 一旦引入黑盒框架，Prompt 字节布局、流式思维块（Preserved Thinking）回传与缓存断点立刻失控。Gorness 直接用 Go context.Context 与通道手写可插拔确定性主循环。
0 / 11
铁律二：严禁对活跃代码库搞向量数据库 RAG 代码高频变动导致向量索引天然过期且丢失符号调用拓扑。Gorness 采用确定性检索黄金组合：ripgrep + Tree-sitter PageRank 符号地图 + 按需 LSP 诊断 + 子目录 AGENTS.md 动态挂载。
4 + BM25
铁律三：常驻核心工具极简化 + 扩展工具延迟检索 + PTC 脚本编排 常驻仅保留 read / edit / write / bash / search；上百个 MCP 与企业连接器工具通过 BM25 search_tools 按需唤醒并支持 Code Mode 批量编排，节省 40%+ 上下文开销。

02 · 统一整体系统架构（Unified 1.0 System Blueprint）

三层宿主结构 × 十大核心子系统，一次完整闭环

不留半成品接口，不搞分期重构。整个 Gorness 应用由原生客户端表现层（macOS Swift 启动器 + Apple 工作台 + 60fps TUI）、无特权 Go 微内核总线与十大正交能力域一次性装配成型，共用唯一一个 SQLite WAL 全局单调递增事件账本（seq）。

01 · cmd/gorness* + studio/macos 融合 OpenCode v2 + Crush + Auriga

单引擎守护服务 + 原生三端同源

  • 原生 Swift 启动器：探测复用或拉起内置 gornessd，管理 Menu Bar 常驻胶囊、系统通知、Keychain 与企业 SSO 桥接。
  • 零依赖内嵌工作台：前端静态资源经 embed.FS 编译进二进制，同源通信零 CORS 暴露；CLI/TUI 通过同一套流式接口无缝接力。
02 · internal/kernel 融合 DeepSeek Harness + Orca

无特权 Go 微内核与预编译事件总线

  • 四条生命周期铁律：服务就绪后才可见；归属直接注册者；拓扑逆序先停消费方再停底层服务；卸载自动清理一切路由、工具、定时器与登记子进程。
  • 零开销拦截点：启动收尾将监听器固化为紧凑切片，空位点耗时 0 ns；连 AgentLoop 自身均可按模式热替换。
03 · internal/provider + prompt 融合 Claude Code + Pi + OpenCode

四大原生传输层与字节级缓存保真

  • 零失真原生协议：直连 Anthropic Messages（原生支持 Adaptive/Preserved Thinking、eager_input_streaming、fallbacks）、OpenAI Responses、Gemini 与本地 Ollama/MLX。
  • 固定前缀铁律：messages[0] 严格只放排序工具定义与静态系统提示；一切动态变化通过尾部 <system-reminder> 注入，重试支持 1.5x 超时放大与脏流重置。
04 · internal/index + context 融合 Aider + Cursor + Gemini CLI

确定性代码智能与锚定增量压缩

  • PageRank 符号图谱：内置 ripgrep + Tree-sitter 提取全仓 AST 引用图并按 Token 预算生成高信噪比 RepoMap，写文件后自动触发 LSP 增量类型检查。
  • 跨会话无损压缩：保留头部与最近 30% 原文轮次，中间段与旧摘要增量归并，压缩后自动重新挂载最近活跃修改的核心文件。
05 · internal/vfs + tools + ptc 融合 Kendr Code + Pi + Claude Code

BLAKE3 原子编辑事务与 PTC 脚本模式

  • 防覆盖事务引擎：写操作前置核对读取时的 BLAKE3 哈希；支持逐 Diff 块勾选部分批准（Partial Hunk Approval）；按 changeKind 精确支持一键还原或连带文件回退。
  • 4+1 工具 + Code Mode：极简常驻面搭配 BM25 延迟工具搜索，支持模型编写沙箱脚本在单轮内批量组合调用外部工具并过滤大结果集。
06 · internal/security + sandbox 融合 Codex + OpenClaw + Auriga

九步权限状态机 · OS 沙箱 · 外部凭证代理

  • 内核沙箱与凭证隔离：macOS Seatbelt / Linux Landlock 强制收紧系统服务通道；子进程环境 0 密钥，由边界外 Egress 代理按可信主机透明注入 Token 并全链路 RedactDeep 脱敏。
  • 内容绑定信任：Hooks、MCP 配置与审批均绑定内容哈希；外部打开文件强制复制只读副本核对 inode，HTML 预览严格限制在无 allow-same-origin 隔离壳中。
07 · internal/alwayson 完整内置 Anthropic Always-On 架构

休眠-唤醒全天候常驻五大原语

  • 单活收件箱与双模定时器：SQLite inbox_events 幂等去重 + 单写者心跳租约 + 连发消息微批合并；timers 独立轮询 Follow-up 与 Cron 入箱。
  • 非阻塞挂起与梦境进化：高危工具触发 Defer 保存现场并立刻释放 Worker；空闲期 Dreamer 自动整理四层指针记忆并提炼固化新 SKILL.md。
08 · internal/fleet + protocol 融合 Anthropic 5 范式 + Gas Town + Goose

可视化多 Agent 舰队与全协议互操作

  • 五模合一编排：对抗盲审、缓存共享子代理、独占 Git Worktree 常驻战队、强类型事件网格、五表共享 SQL 黑板，配齐 Witness 巡检与 Refinery 串行合并队列。
  • 零壁垒生态：原生兼容 .agents/skills/、全传输双向 MCP（默认不盲信自报 readOnlyHint）、ACP Server/Host 与 SSH 远端免安装守护注入。
03 · Anthropic《Building Always-On Agents》五大原语内核化设计

99% 时间零 Token 深度休眠，事件到达毫秒级精准唤醒

01 · EVENT INBOX
唯一事实源收件箱
快速落盘去重 ACK，深度提示注入检查放到 Run 内；单 Inbox 严格绑定单活 Worker 租约，进程强杀重启自动续跑未完事件。
02 · DURABLE TIMERS
主动性唤醒引擎
Agent 可随时调用 set_followup 给自己定闹钟检查异步构建或外部回复；周期 Cron 自动推进下次触发槽位并投递 Inbox。
03 · POINTER MEMORY
只存不可重查之物
Issue/PR 等外部数据只存指针防过期；启动仅加载轻量索引保住缓存命中，空闲期运行 Dreaming 归并冗余并沉淀自进化技能。
04 · DEFERRED CALL
挂起绝不卡死队列
遇越权或不确定决策时保存半完成工具栈立即收尾本轮 Run，Worker 继续消费其他事件；用户批复卡片回流 Inbox 后无缝接续。
05 · PACED OUTBOX
克制打扰赢得信任
屏蔽后台百步排障噪音，只发结论或审批卡；发送前校验 reported.md，无新进展自动走 Silent 静默结束。

十条贯穿全仓的硬边界（每一条均绑定自动化单测）

        

          

            1. 单调全局序号（Global Monotonic seq）
            messages、agent_runs、run_steps、file_snapshots 共用同一递增序列；/fork 与 /rewind 按单个事务精确截断或还原新建/修改文件。
          

          

            2. 九步固定顺序 PermissionGate
            硬黑名单底线 → Plan 只读拦截 → 未信任项目配置降级 → Hook 询问 → 语义级只读判定（MCP 自报 readOnlyHint 一律不免审）→ 自启动配置保护 → 必问工具 → 内容指纹授权 → 模式分支。
          

          

            3. 派生上下文权限单调收紧
            子代理、Code Mode 脚本、Always-On 后台唤醒、外部 ACP 委托代理，其工具集、目录规范边界（解析软链接后）与沙箱策略严格继承父级交集，绝不允许提权。
          

          

            4. 同意永远绑定“内容指纹”而非文件名
            项目级 Hooks、.mcp.json、审批 Diff 块与命令放行均绑定 BLAKE3 哈希；文件或工作区路径一旦变动，旧信任立刻失效并回退人工确认。
          

          

            5. 沙箱零密钥 + 全链路单一脱敏器
            工具环境变量不含任何 LLM Key 或企业会话 sid；日志、落库、错误回显统一经过唯一 RedactDeep 清洗。
          

          

            6. 安全外部查看与零逃逸预览壳
            调用 macOS open 前仅对白名单文档复制只读副本并用 FD+inode 复核；模型生成的 HTML 一律在无 allow-same-origin 且禁外网跳转的隔离预览壳中渲染。
          

          

            7. 工具如实禀报语义（Honest Tool Reporting）
            结果截断、部分写入失败、超时后状态未知（严禁谎报“未执行，可安全重试”）必须如实结构化告知模型与前端工具卡。
          

          

            8. 审批卡片 500ms 防误触冷静锁
            新审批卡切入视口后 500ms 内屏蔽批准点击与快捷键连击，杜绝连续拍板误放行高危指令。
          

          

            9. 同源守护与子进程全生命周期陪葬
            引擎仅应答本机同源页面与认证 CLI，绝不挂载宽泛 CORS；所有拉起的 MCP、LSP、Hook 与 Worktree 进程统一登记进程组，引擎退出零孤儿残留。
          

          

            10. 零 Mock 框架纯构造注入可测性
            每个测试独占临时数据目录、带符号链接覆盖的工作区与 FakeHome，直接通过内存 Handler.ServeHTTP 跑通全链路竞态测试（go test -race）。
